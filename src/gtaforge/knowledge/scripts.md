# Scripts (asi / SHVDN / Menyoo / Lua)

## C++ asi (ScriptHookV SDK)

- `gtaforge new <name> --kind cpp` writes CMakeLists.txt, `src/main.cpp` and
  `inc/natives.h` (current native DB, all 6,701 natives, generated by
  `gtaforge natives --header`; the SDK's own natives.h is from 2016).
- Entry point: `scriptRegister(module, ScriptMain)` on DLL_PROCESS_ATTACH,
  `scriptUnregister(module)` on detach; `ScriptMain` loops with `WAIT(0)`.
  Natives run only inside a registered script; never from `CreateThread`.
- Natives are namespaced: `PLAYER::PLAYER_PED_ID()`, `TASK::TASK_PLAY_ANIM(...)`.
- `gtaforge compile` finds MSVC with vswhere, captures vcvars64, builds with
  CMake + Ninja into `build/`; static CRT, `.asi` output.

## C# (SHVDN v3)

- `--kind shvdn`: net48 project; `gtaforge compile` passes
  `SHVDN_REF` = the folder of `ScriptHookVDotNet3.dll` (game folder or a tool dir).
  Output `bin/Release/<name>.dll` -> `scripts/`.
- Enhanced needs the Enhanced SHVDN build (3.9.x).

## Static checks (`gtaforge script check` / `gtaforge check`)

- `NS::NAME(` calls: the native exists (current or old name), namespace, argument count.
- `Function.Call(Hash.NAME, ...)` / `(Hash)0x...`: exists, argument count.
- DllMain without scriptRegister is an error; CreateThread is a warning.
- XML well-formed; Menyoo Spooner `ModelHash` = joaat(`HashName`).

## Menyoo Spooner

`--kind menyoo` writes `menyooStuff/Spooner/<name>.xml` (`SpoonerPlacements`,
Type 1 ped / 2 vehicle / 3 object); payload goes to the game's `menyooStuff/`.

## Lua

FiveM/RedM only (fxmanifest.lua); single-player GTA V has no Lua runtime.
`gtaforge script lua .` needs luajit or luac.

# Map and MLO interiors

- A new interior is a shell (drawable), portals, rooms, a ymap, and an interior
  proxy; without portals/rooms the player falls through or the AI cannot path.
- Edit with CodeWalker (V) or RageForge (VI); export with the same tool.
- Test: teleport in, walk every room, shoot, drive out; save/reload inside.
- MLO = multi-level interior; the name is not a file extension.

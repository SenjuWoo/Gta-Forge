# RPF archives

- `gtaforge rpf doctor` - which tools are installed.
- `gtaforge rpf info <archive>` - RPF7 header (entry count); the TOC is encrypted.
- `gtaforge rpf list|find|extract` - needs ragekit (CLI); CodeWalker is GUI.
- GTA VI RPF9: `gtaforge vi tools` / `gtaforge vi build-6to5m` (6ixpack).
- Back up an archive before any edit. Never edit the game's only copy.
